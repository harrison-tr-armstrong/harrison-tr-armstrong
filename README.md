## Featured Project

### [NEO Asteroid Detection](YOUR_NEO_PROJECT_REPO_URL)

**Computer vision for astronomical image analysis.**

An ongoing project exploring how computer vision techniques can identify and localise asteroid trails in astronomical images.

The aim is to develop a reliable, modular pipeline that progresses from raw image data to model predictions, with a future user interface for image-based detection.

**What I'm building**

- **Multi-dataset ingestion:** Working with five source datasets in the NEOBench collection.
- **Data validation:** Inspecting image files, annotation availability, dataset structures, and labelling consistency.
- **YOLO annotation processing:** Working with bounding-box labels for the `streak` class.
- **Reusable data pipeline:** Developing components for loading, retrieving, inspecting, and validating individual samples.
- **Computer vision integration:** Preparing the data pipeline for object detection training and evaluation.
- **Future application:** Planning an image-upload interface with visualised detection results.

**Current stage:** Dataset loading and annotation verification.

**Planned next steps:** Model integration, evaluation, inference, and an interactive detection interface.
